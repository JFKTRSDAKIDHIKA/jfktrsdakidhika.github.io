## TL;DR

- 提出 DNNFusion：一种针对 DNN 推理的高级算子融合编译技术。
- 超越传统的 element-wise fusion，支持跨 reduction boundary 的融合（如 Conv+BN+ReLU 中间不 materialize）。
- 在移动/边缘设备上减少 memory traffic，实现 1.2-2.3× 加速。
- 关键技术：graph-level pattern matching + code generation for fused kernels。

## Insights

- Operator fusion 是所有 DNN compiler 的核心优化（TVM, XLA, TensorRT 都做）。
- 本文的贡献在于 "advanced fusion"：打破 reduction 边界，需要更复杂的 code generation。
- 对 accelerator 设计的影响：如果 compiler 能融合更多算子，accelerator 的 on-chip buffer 压力减轻。
