## TL;DR

- 提出 AStitch 编译框架：为 GPU 上的 memory-intensive ML 算子启用跨算子融合 + 多维 tiling 优化。
- 关键创新：将 fusion 空间从传统的 1D (operator chain) 扩展到多维（涵盖 batch, spatial, reduction 维度）。
- 在训练和推理的 memory-intensive 算子上获得显著加速（相比 TVM/XLA）。

## Insights

- "Memory-intensive" 算子（LayerNorm, Softmax, element-wise）是 LLM 推理的瓶颈之一，AStitch 直接 targeting 这个问题。
- 与 FuseMax (MICRO 2024) 思路相通：都是通过更激进的 fusion 减少 memory traffic。
- 对 accelerator 设计的启示：如果 compiler 能做好 fusion，硬件可以更简单。
