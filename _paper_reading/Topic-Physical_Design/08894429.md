## TL;DR

- Compact-2D：用类似 2D 的 PD 流程设计双层 gate-level 3D IC。
- 核心思想：将 3D 设计 "压平" 为 2D footprint，复用 2D EDA 工具。
- Sung Kyu Lim (Georgia Tech) 组的经典工作。

## Problem

Gate-level 3D IC 缺乏 EDA 工具支持，能否复用现有 2D PD 工具？

## Method

1. 将两层电路合并到一个 2D 平面 (folding)
2. 用标准 2D P&R
3. Unfolding 恢复 3D 结构 + TSV 插入

## Insights

- "Reuse 2D tools for 3D" 是实用主义策略。
- 与 Pin-3D (同一组) 互补：Pin-3D 是原生 3D PnR。
