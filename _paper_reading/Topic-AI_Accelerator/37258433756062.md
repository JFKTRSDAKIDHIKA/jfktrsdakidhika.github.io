## TL;DR

- LongSight：支持超长上下文 LLM 推理的硬件架构。
- 长上下文 (100K+ tokens) 的 KV cache 占满 HBM → 需要新方案。
- 用 compute-near-memory 处理 KV cache 的 attention 计算。

## Problem

LLM 长上下文推理中 KV cache 随 seq_len 线性增长，导致 memory 不足或 bandwidth 瓶颈。

## Method

将 attention 计算下推到 KV cache 存储位置附近（near-memory compute for attention）。

## Insights

- 长上下文是 LLM 的重要趋势 (GPT-4 128K, Claude 200K)。
- KV cache 是 memory 瓶颈 → PIM/NMC 的天然应用场景。
