## TL;DR

- ATiM：PIM 架构的 tensor program 自动调优框架。
- 类似 TVM/Ansor 对 GPU/CPU 的作用 → ATiM 对 PIM。
- 自动搜索最优 tiling, data layout, scheduling for PIM。

## Problem

PIM 的编程模型和优化空间与 GPU/CPU 不同（bank parallelism, limited compute），缺乏自动调优工具。

## Method

1. 定义 PIM-specific schedule primitives
2. Search space: bank-level tiling + data layout + compute-communication overlap
3. Autotuning: cost model + evolutionary search

## Insights

- PIM 生态需要编译器/autotuner 支持才能普及。
- 与 UniNDP (DSE 分类) 的思路互补。
