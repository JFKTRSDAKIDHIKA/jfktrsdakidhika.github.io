## TL;DR

- OptiPIM：用 ILP (Integer Linear Programming) 优化 PIM 的 workload mapping。
- 将 PIM 的数据布局 + 操作调度 formulate 为 ILP 问题。
- 保证找到最优解（given model fidelity）。

## Problem

PIM 的性能高度依赖 data placement 和 operation scheduling，手动优化不可行。

## Method

1. 建模 PIM 系统的 memory banks, compute units, interconnect
2. ILP 变量：数据放置、操作分配、通信调度
3. 目标：minimize latency/energy subject to capacity/bandwidth constraints

## Insights

- ILP 保证最优但计算复杂度高 → 适合 offline 编译，不适合 runtime。
- 与 Timeloop (exhaustive/heuristic) 和 BO (black-box) 是不同思路。
