## TL;DR

- HeterRAG：面向 RAG 管线的异构 PIM 加速。
- RAG 包含 retrieval (向量搜索) + generation (LLM) 两阶段，各有不同计算特征。
- 异构 PIM：向量搜索用 DRAM-PIM，generation 用 HBM-PIM。

## Problem

RAG 管线中 retrieval 和 generation 的计算/访存模式不同，单一架构无法同时优化。

## Method

1. Retrieval: high-parallelism similarity search → DRAM-PIM (high capacity)
2. Generation: bandwidth-bound GEMV → HBM-PIM (high bandwidth)
3. Pipeline scheduling 减少端到端延迟

## Insights

- RAG 是 LLM 的重要应用范式 → 硬件需要支持整个 pipeline。
- Heterogeneous PIM 是务实的方案（不同 memory tier 做不同事情）。
