## TL;DR

- Trapezoid：同时高效支持 dense 和 sparse 矩阵乘的加速器。
- 核心创新：梯形 (trapezoid) PE array 布局，在 dense mode 和 sparse mode 间平滑切换。
- 避免了传统方案中 dense/sparse 两套硬件的面积浪费。

## Problem

DNN 中既有 dense layer (GEMM) 也有 sparse layer (pruned)。一套硬件如何同时高效处理？

## Method

1. Trapezoid PE array: asymmetric 布局支持不同稀疏度
2. Dense mode: 全 PE 利用
3. Sparse mode: 根据稀疏度动态分配 PE

## Insights

- "One architecture fits all" 的设计哲学。
- Dense/Sparse 切换是实际部署中的刚需。
