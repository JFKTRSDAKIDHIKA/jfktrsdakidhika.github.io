## TL;DR

- Kelle：联合设计 KV cache 策略和 eDRAM 硬件用于边缘 LLM。
- 边缘设备 DRAM 有限 → 用 on-chip eDRAM 存 KV cache。
- Cache eviction 策略与 eDRAM 物理特性联合优化。

## Problem

边缘 LLM 推理的 KV cache 大于 on-chip SRAM 但频繁访问。eDRAM 是合适的中间层吗？

## Method

eDRAM-based KV cache + attention-aware eviction policy + refresh 优化。

## Insights

- eDRAM 在移动 SoC 中已有应用（Apple A-series）。
- KV cache 管理是 LLM 硬件设计的核心挑战之一。
