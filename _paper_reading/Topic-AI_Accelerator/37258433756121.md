## TL;DR

- Pimba：面向 Post-Transformer 模型（Mamba, RWKV 等 SSM）的 PIM 加速。
- SSM 的核心操作 (selective scan) 是 sequential + memory-bound → 适合 PIM。
- 针对 SSM 的 state update 模式优化数据布局。

## Problem

Post-Transformer (SSM) 模型的计算模式与 Transformer 不同，传统加速器和 PIM 设计都不适用。

## Method

1. 分析 Mamba/SSM 的 memory access pattern
2. 优化 PIM bank 的 state vector 存储布局
3. Pipeline scan operations across banks

## Insights

- Post-Transformer 硬件加速紧跟 MARCA (ICCAD 2024) 之后。
- SSM 是否真能替代 Transformer 还未定论，但硬件社区已在提前布局。
