## TL;DR

- 用 PIM + PNM 联合加速 RAG (Retrieval Augmented Generation)。
- PNM 做 embedding/retrieval，PIM 做 attention GEMV。
- 协同调度减少数据搬移。

## Problem

RAG 管线的 retrieval + generation 各自有 memory 瓶颈。

## Method

PNM (near-storage) 做向量数据库查询 + PIM (near-DRAM) 做 LLM decode。

## Insights

- 与 HeterRAG (ASPLOS 2025) 思路类似但系统层次不同。
- PIM + PNM 是 Samsung 技术路线的体现。
