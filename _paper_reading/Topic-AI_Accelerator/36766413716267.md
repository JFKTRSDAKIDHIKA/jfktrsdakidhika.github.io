## TL;DR

- 提出完全无 GPU 的 LLM 推理系统，用 CXL-attached PIM 替代。
- 核心论点：LLM decode 是 memory-bound → PIM 比 GPU 更 cost-effective。
- 通过 CXL 接口将 PIM 模块接入标准服务器。

## Problem

GPU 推理 LLM 成本高（GPU 贵 + 大部分算力在 decode 时浪费）。能否用廉价的 PIM 替代？

## Method

1. CXL-PIM devices 提供高聚合带宽
2. Model parallelism across PIM devices
3. Host CPU 做 control + lightweight compute, PIM 做所有 GEMV

## Insights

- 大胆命题："GPU-Free LLM Inference"。
- 经济账：PIM 每 GB 成本 << GPU HBM 每 GB 成本。
- 现实挑战：CXL latency、PIM 算力限制、软件生态。
