## TL;DR

- ComPASS：解决 processor 和 PIM 并发执行时的调度冲突。
- 当 CPU 和 PIM 同时访问同一 bank → bank conflict。
- 提出兼容性调度策略：保证 PIM 不阻塞 CPU 的正常访存。

## Problem

PIM 操作需要独占 DRAM bank，但 host processor 也要访问同一内存 → 冲突如何调解？

## Method

时间分片 + 优先级调度：PIM 利用 CPU idle 周期，或选择 CPU 不访问的 bank。

## Insights

- 实际部署 PIM 的关键工程问题（不是每个人都注意到的）。
- PIM 不能「独占」内存 — 必须和 host 共存。
