## TL;DR

- Adelia：4nm 工艺的 LLM 推理芯片（ISSCC 2025 发表）。
- 专为 Generative AI (GPT-like) 推理优化。
- 高算力密度 + 大容量 on-chip memory + 高带宽接口。

## Problem

LLM 推理需要超高带宽和大量权重存储，如何在最先进工艺下最大化效率？

## Method

4nm 工艺 + 大面积 SRAM + 高频 MAC array + 定制数据通路。

## Insights

- ISSCC 级别代表最先进的芯片实现。
- 4nm for LLM 是产业方向（NVIDIA H100/B100 也是类似思路）。
