## TL;DR

- AMD 提出 **Folded Banks** 概念：将传统 2D memory bank 垂直"折叠"到多个 3D 层中。
- 利用 3D stacking 的高密度 TSV 实现 bank 内部的宽数据通路，同时减少平面面积占用。
- 比传统 2D bank 组织获得更高带宽密度和更低能耗。
- 适用于 on-chip SRAM cache 和 stacked DRAM 的新型组织方式。

## Insights

- 与 2008 Loh 的 "true 3D DRAM" 思想一脉相承：重新设计 memory organization 来利用 3D 特性。
- "Folding" 本质是把 bank 的 bitline/wordline 跨层分布 → 缩短单层的 wire length → 提速。
- 对 HBM-next 和 on-chip memory 设计有直接指导意义。
